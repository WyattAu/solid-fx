# src/extras — non-react-bits sources

Ports from sources other than react-bits (Magic UI, Kibo, Cursify, …). One
tree per source: `src/extras/<source>/<Category>/<Name>/<Name>.tsx`.

Rules — see `LICENSE-SOURCES.md` (license vetting is mandatory before the
first port of a source) and `PORTING.md` (the translation contract applies
to every source). react-bits ports stay in `src/content/`: the upstream sync
workflow diffs that tree against react-bits only.
